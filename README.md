# Taller Git 1

Proyecto individual para practicar el ciclo básico de Git y GitHub.

## Descripción
Este repositorio demuestra cómo crear un repositorio, registrar cambios, revisar el historial y deshacer modificaciones de forma segura.

## Instalación

1. Clonar el repositorio.
2. Entrar en la carpeta del proyecto.
3. Revisar el README.

## Comandos utilizados

- `git init`: crea un repositorio Git local y su carpeta `.git`.
- `git add`: coloca cambios en el área de preparación (staging).
- `git commit`: guarda una versión identificable del proyecto.
- `git push`: envía los commits del repositorio local al remoto.
- `git status`: muestra el estado de los archivos y del staging.
- `git diff`: muestra cambios aún no confirmados.
- `git log`: consulta el historial de commits.
- `git restore`: descarta cambios del archivo o retira cambios del staging con `--staged`.

## Publicación en GitHub

1. Crear un repositorio vacío llamado `taller-git-1` en GitHub.
2. Sustituir la URL remota de ejemplo por la URL real.
3. Ejecutar `git branch -M main` y `git push -u origin main`.
