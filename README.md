# Taller Git 1

Proyecto individual para practicar el ciclo básico de Git y GitHub.

## Descripción
Este repositorio demuestra cómo crear un repositorio, registrar cambios, revisar el historial y deshacer modificaciones de forma segura.

## Instalación

1. Clonar el repositorio.
2. Entrar en la carpeta del proyecto.
3. Revisar el README.
